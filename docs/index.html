What it does

Everything a lineup callout needs, nothing it doesn't.

AUTO-DETECT

Knows your map before you do

Reads CS2's official Game State Integration to detect the map, your team, and round phase automatically — no manual setup, no alt-tabbing to check.

3-IMAGE LINEUPS

Stand. Exact spot. Aim.

Every lineup shows the general area, the precise footing, and exactly where to look — because a step to the left is the difference between a perfect smoke and a wasted one.

SPAWN SMOKE

Built for the first ten seconds

A dedicated tab for spawn-position throws, with a full map overview image and every spawn's lineup one tap away.

ZOOM

See it properly

Open any image full-size in one click — no more squinting at a thumbnail to figure out exactly where the crosshair needs to sit.

SIDE + ZONE FILTERS

T, CT, and by the site

Filter by side and by A-site / Mid / B-site so you're looking at four lineups instead of forty.

CLICK-THROUGH

Never blocks your click

Toggle mouse capture with one hotkey so the overlay never eats an input while you're mid-round.

Setup

Three steps. No configuration screens.

  1. 01

    Install it

    Run the installer. It finds your CS2 install and configures itself — you won't need to touch a config file.

  2. 02

    Launch CS2

    Easy Line Up sits quietly in the corner. The moment CS2 reports a map, the panel updates on its own.

  3. 03

    Play

    Tap a lineup, glance at it, throw it. Press F9 to hide the panel whenever you don't need it.

Before you click "Run anyway"

About that Windows warning

Easy Line Up is an independent, unpaid project — code-signing certificates cost several hundred dollars a year, which isn't something a free hobby tool budgets for. Windows SmartScreen flags any app without one as "unrecognized," regardless of what the app actually does.

The source code is open — if you want to check exactly what it does before running it, that's what it's there for.
